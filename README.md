# To-Do List Project

A simple to-do list project for tracking tasks and planning work.

## Getting Started

- Open `index.html` in a browser.
- Enter a task and click **Add Task** or press Enter.
- Click the checkmark to complete a task, or the cross to delete it.

## Project Structure

- `README.md` - Project overview
- `TODO.md` - Task list and next steps
- `index.html` - Main app page
- `style.css` - App styling and animations
- `script.js` - Task behavior and animations

## Notes

- New tasks animate into view.
- Completed tasks toggle a visual state.
- Deleted tasks animate out before removal.
- Customize the app by editing CSS and JavaScript.
